# 전환사채 평가

이항격자로 전환사채를 평가하고 조서를 엑셀로 내보내는 스트림릿 앱이다.

## 무엇을 하나

- 계약조건을 넣으면 전환권·조기상환청구권·매도청구권을 순차 차감으로 분리한다
- TF와 GS 두 모형을 나란히 계산해 비교한다
- 리픽싱은 상태확장(정확) 또는 근사 세 가지 중에서 고른다
- 주가를 받아 변동성을, 만기수익률을 받아 선도이자율을 산출한다
- 기업회계기준서 제1032호 문단 31에 따라 최초 인식 배분과 분개를 만든다
- 조서를 값 또는 수식 형태로 내보낸다

## 실행

```
pip install -r requirements.txt
streamlit run cb_app.py
```

## 스트림릿 클라우드에 올리기

1. 이 폴더를 깃허브 저장소로 만든다
2. share.streamlit.io 에서 New app 을 누르고 저장소와 `cb_app.py` 를 고른다
3. Deploy 를 누르면 몇 분 뒤 주소가 나온다

`requirements.txt` 를 저장소 루트에 두어야 필요한 패키지가 설치된다.
`pykrx` 와 `yfinance` 가 설치되지 않는 환경이라면 두 줄을 빼도 앱은 돌아간다.
주가 자동 수집만 막히고 파일 붙여넣기는 그대로 된다.

## 화면

| 탭 | 내용 |
|---|---|
| 구성요소 | 순차 차감, TF·GS 비교 |
| 회계처리 | 최초 인식 배분과 분개 (100 기준·전액 기준) |
| 이자율곡선 | 현물·선도이자율, 부트스트래핑 과정 |
| 주가·변동성 | 수집한 종가와 변동성 |
| 의사결정 | 영역 그림과 정산 분포 |
| 상각표 | 유효이자율 역산 |
| 민감도 | 변동성·할인율 |
| 검산 | 다섯 항목 |
| 조서 | 엑셀 내려받기 |

## 조서 두 형식

| | 값 조서 | 수식 조서 |
|---|---|---|
| 성격 | 계산 결과 스냅샷 | 엑셀에서 다시 계산됨 |
| 용도 | 제출용 | 검토·실험용 |
| 상태확장 | 가능 | 경로가중치로 대체 |

트리 하나가 시트 하나이고, 모든 시트의 머리 17행이 같은 형태다.

## 한계

- 리픽싱 기준주가를 조정일 종가로 단순화했다. 계약은 가중산술평균주가를 쓴다
- 조기상환 청구 시차(지급기일 60일 전~30일 전)를 반영하지 않는다
- 발행자가 가치극대화만 추구한다고 가정한다
